# Hospital Patient Management System

This project is a Hospital Management System developed as part of a group assignment by Mashael Saeed, Sarah Elshiaty, and Seifeldin Elshiaty.  
It manages patient records, emergency room queues, treatments, and history tracking using C++ data structures like linked lists, queues, and stacks.

## Features
- Add new patients with details (name, gender, age, condition)
- View all registered patients
- Manage Emergency Room (ER) queue with triage levels (Critical, Serious, Stable)
- Treat ER patients and Regular patients
- Undo last treatment operation
- Search for patients by name
- View ER queue status

## Technologies Used
- Language: C++
- Data Structures: 
  - Linked List (Patient Records)
  - Queue (ER Management)
  - Stack (Treatment History)

## Setup Instructions
1. Clone this repository:
    ```bash
    git clone https://github.com/M1sh13l/Hospital-System.git
    ```
2. Open `HospitalSystem.cpp` in any C++ IDE (e.g., Code::Blocks, Visual Studio, or VS Code).
3. Compile and run:
    ```bash
    g++ Projecttest.cpp -o hospital
    ./hospital
    ```
